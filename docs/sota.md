# 高速 k-means の事前調査と採用判断

調査日: **2026-11-17**。この版の Elkan、Exponion、CSR カーネルを実装する前に、以下の一次資料を確認した。外部のクラスタリング実装を転載せず、公開された数式から独立に実装した。

## 「最速」を一つに決められない理由

実行時間は標本数 `n`、次元数 `d`、クラスタ数 `k`、クラスタの分離、初期中心、停止条件、数値精度、CPU/GPU、メモリ帯域で変わる。距離評価を減らしても、境界配列の更新・分岐・ソートが重ければ遅くなる。初期化を含めるかどうかでも順位が変わる。

そのため、論文が特定の条件で報告した最大倍率を、別のハードウェアや本ライブラリの性能として引用しない。**mykmeans が世界最速、または現在の SoTA 実装より速いことを示す比較実験は行っていない。** 同梱の実測比較対象は scikit-learn と本ライブラリの各方式。

## 確認した方式

| 方式・一次資料 | 高速化の対象と要点 | この版での扱い |
| --- | --- | --- |
| [Elkan, 2003](https://cdn.aaai.org/ICML/2003/ICML03-022.pdf) | 各点・各中心の下界と中心間距離による枝刈り。境界の記憶量が `O(nk)` | 密行列・CSR とも独立実装 |
| [Hamerly, 2010](https://cs.baylor.edu/~hamerly/papers/sdm_2010.pdf) | 各点の上界と、競合中心への下界を一つずつ管理 | 密行列に独立実装 |
| [Yinyang, 2015](https://proceedings.mlr.press/v37/ding15.html) | 中心をグループ化し、グループ単位の下界を管理 | 調査済み、未実装 |
| [Exponion / Newling & Fleuret, 2016](https://proceedings.mlr.press/v48/newling16.html) | 幾何学的な候補球で再評価する中心を限定する、低次元向けの exact 系方式 | 密行列に変種を独立実装。論文の部分ソートを全近傍ソートに置換 |
| [Geometric-k-means, 2026-01-27](https://link.springer.com/article/10.1007/s10994-025-06891-1) | スカラー射影を使い、所属変更に寄与し得る点に処理を集中。従来型の距離境界配列を使わない方式 | 調査済み、未実装。論文の実験だけから全条件での優位は判断しない |
| [FastKPP 著者実装・論文案内](https://github.com/GuilleRodri/FastKmeansPP) | 三角不等式・ノルムによる候補排除で D² sampling の初期化を高速化。2025 年の原論文と 2026 年のソフトウェア論文 | 三角不等式による距離省略を独立導出して採用。FastKPP 全体の再実装ではない |
| [SuperKMeans, 2026-03-20](https://arxiv.org/html/2603.20009v1) | 高次元埋め込み向け。回転、部分 GEMM、ADSampling による次元剪定、検索 recall に基づく早期停止 | 調査済み、未実装。検索品質を評価する設定と標準 SSE 停止を区別する |

SuperKMeans は埋め込み検索の品質を保つことを主眼に置き、確率的な次元剪定と recall による停止を含む。そこでの「品質低下がほぼない」という報告を、すべての点の厳密最近傍割当や通常の Lloyd の停止条件と同一視しない。Flash-KMeans の論文で報告された NVIDIA H200 上の最大 17.9 倍は著者の実験結果であり、このパッケージの測定値ではない。GPU の精度設定・データ転送・初期化も比較条件になる。

## 採用した設計

通常の weighted Euclidean k-means を扱い、標準 API の意味を保ちながら、実行方式を選べる構成にした。

1. **Lloyd**: 直接距離カーネルとブロック GEMM を使い分ける。全 `n × k` 距離行列を保存しない。
2. **Hamerly**: 点ごとの少数の上下界を更新し、省略が有効な場合に距離計算を減らす。
3. **Elkan**: `n × k` の float64 下界を確保し、各候補を細かく判定する。大きい `n` と `k` では記憶量に注意する。
4. **Exponion 変種**: Hamerly 型の境界と中心近傍の候補球を用いる。中心ごとの全ソートを採用しており、原論文の部分ソートによる計算量と同じとは主張しない。中心間領域は `O(k²)`、ソートは反復あたり `O(k² log k)`。
5. **CSR**: 密な観測行列を作らない独立 Lloyd / Elkan。中心は通常どおり密な `k × d` 配列。

Elkan / Hamerly / Exponion の省略は三角不等式に基づく。実数の厳密演算での規則と、浮動小数点プログラムの全ビット一致は異なる。境界には保守的な丸めの余裕を加え、初期中心を揃えた比較・境界近傍・極端なスケール・公開中心による最終再割当をテストした。区間演算による完全な誤差証明を行った実装ではない。

## 初期化の三角不等式フィルタ

点 `x` の最近傍既存中心を `a`、新候補を `c`、既存の距離を `r = ||x-a||` とする。

```math
\|a-c\| > 2r
\quad\Longrightarrow\quad
\|x-c\| \geq \|a-c\| - \|x-a\| > r.
```

したがって、この点では `min(r², ||x-c||²)` を更新しなくてよい。残りの点だけ直接距離を計算する。greedy local trials、重み付き potential、乱数の使用順は変えない。FastKPP でいう exact sampling と、scikit-learn と同一 seed で同一の中心列になることも別の性質。

境界判定にも費用がかかるため、`d >= 8, n >= 1024, k >= 8` を入口とし、256 点までの等間隔標本で省略率を見積もる。`d >= 64` では 60%、それ未満では 75% を目安にフィルタを選ぶ。この見積もりは実行経路だけを決め、所属や距離を近似しない。小さい問題や省略が少ない候補には全直接距離を使う。閾値は性能ヒューリスティックであり、最適性の保証ではない。

## この調査からの実用上の判断

低次元・多反復では Exponion / Hamerly を比較する。高次元では SIMD と BLAS の効率が重要なので、Lloyd も必ず比較する。Elkan の距離評価回数が少なくても、そのことだけで選ばない。`auto` は簡単な固定規則であり、これらの候補を実測して選ぶ自動チューナーではない。
